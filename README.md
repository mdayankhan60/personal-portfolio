# Mohammed Ayan Khan – Personal Portfolio Website

A professional, responsive single-page portfolio built with **HTML5**, **CSS3**, **Bootstrap 5**, and **Vanilla JavaScript**.

## 🚀 Quick Start

Simply open **`index.html`** in any modern browser — no build tools, no server required.

```
personal-portfolio/
├── index.html       ← Open this
├── style.css        ← All custom styles
├── script.js        ← All interactivity
└── assets/
    ├── profile.jpg  ← Mohammed Ayan Khan's photo
    └── college.jpg  ← C. Byregowda Institute of Technology (CBIT) photo
```

## 🛠️ Customization Tips

- **Colors** — Edit `--primary` and `--accent` in `:root {}` inside `style.css`
- **Roles** — Edit the `roles` array at the top of `script.js`
- **Projects** — Duplicate a project card `<article>` in `index.html`
- **Skills** — Adjust `aria-valuenow` and the inline `style="width: X%"` on each `.progress-bar`
- **LinkedIn URL** — Search for `href="#"` near `bi-linkedin` and replace with your real URL
